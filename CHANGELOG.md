# Changelog

All notable changes to this project will be documented in this file.

## 2.0.0 - 2026-06-01

- Added automatic upload for local Markdown images before publishing posts
- Added ASCII-safe, hash-suffixed media filenames for non-ASCII local image paths
- Kept publish commands in the command palette while removing editor title toolbar entries
- Updated the sample Markdown post to cover Markdown rendering and local image uploads together

## 1.0.0 - 2026-05-30

- Added a Marketplace-ready VS Code extension manifest
- Added bilingual release documentation
- Added VSIX packaging and installation scripts
- Added release asset verification for README, LICENSE, CHANGELOG, and icon packaging
